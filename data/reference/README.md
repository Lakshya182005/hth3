# Reference Images Directory

Place reference images for each known campus hunt location in subdirectories named after their `location_id`:

```
data/reference/
  ├── clock_tower/
  │   ├── photo1.jpg
  │   ├── photo2.jpg
  │   └── photo3.jpg
  ├── library_atrium/
  │   ├── atrium1.jpg
  │   └── atrium2.jpg
  └── science_quad/
      └── quad1.jpg
```

## Guidelines:
1. **Diversity**: Capture reference photos across different angles, distances, times of day, lighting conditions (sunny, overcast, twilight), and different smartphone cameras.
2. **Distinctness**: Ensure photos focus on the distinct architectural, sculpture, or landmark features of the location.
3. **No Cross-Contamination**: NEVER copy or share images between `data/reference/` and `data/validation/`. They must represent completely separate captures.
